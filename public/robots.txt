# to be able to FETCH a page to be told that. A Disallow here would block the
# fetch instead, which leaves any URL that is linked from anywhere eligible to
# be indexed with no snippet — a worse search result than no result. So: allow
# the crawl, and let each page say whether it belongs in an index.
