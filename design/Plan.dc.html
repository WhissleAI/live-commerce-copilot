Deliberately not doing

Three things, and why — two of them changed.

A phone glance view

Splitting the interaction model while the desktop one is still being proven costs a week and answers a question nobody has asked yet. Revisit after the first pilot show.

Defeating bot detection

Still not doing this. What changed is the premise: the grid was never refused, it was gated on a session. The seller signs in once, in a real browser, themselves — nothing here types a credential, and the profile is kept like a password. With the session, discovery is reliable and preparable; without it, the empty state says exactly that.

Unlocking L4

An eBay adapter now exists, sandbox-only, switched on per show. L4 still stays locked: it needs a show that writes to eBay and a rollback rate under 10% across five shows. The reason on every surface changed from “no live adapter” to “until a show writes to eBay”.

What gets tested as we go

Phase 0 adds an auth test per guarded route and a two-owner promotion test. Phase 1 adds a contract test per newly-called endpoint, so a shape change breaks a test rather than a screen. Phase 2 adds a migration round-trip and a cost-reconciliation test — the per-show rows must sum to the door totals. Phase 3 extends the guardrail eval with the flagged-wrong cases the operators produce, which is the first time the suite learns from live traffic rather than from its author.
